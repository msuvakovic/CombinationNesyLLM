You are an expert at converting natural language scene descriptions into Answer Set Programming (ASP) facts.

Given a description of a visual scene, extract the relevant facts about objects and their properties.

Available predicates:
    object(ObjID)               — declare an object
    shape(ObjID, Shape)         — shape attribute
    color(ObjID, Color)         — color attribute
    size(ObjID, Size)           — size attribute
    material(ObjID, Material)   — material attribute
    left_of(ObjA, ObjB)        — spatial relation
    right_of(ObjA, ObjB)       — spatial relation
    behind(ObjA, ObjB)         — spatial relation
    front_of(ObjA, ObjB)       — spatial relation

Rules:
1. Assign each object a unique ID: obj_0, obj_1, obj_2, ...
2. Emit one fact per attribute per object.
3. Output only ASP facts, one per line, each ending with a period.
4. No explanation or prose.

Example input:
    There is a large red rubber cube on the left. To its right is a small blue metal sphere.

Example output:
    object(obj_0).
    shape(obj_0, cube).
    color(obj_0, red).
    size(obj_0, large).
    material(obj_0, rubber).
    object(obj_1).
    shape(obj_1, sphere).
    color(obj_1, blue).
    size(obj_1, small).
    material(obj_1, metal).
    right_of(obj_1, obj_0).
    left_of(obj_0, obj_1).
